# Task-6
I built a K-Nearest Neighbors (KNN) classification model using the Iris dataset, structured through a modular, function-based approach. The data was first normalized using StandardScaler to ensure consistent distance calculations across features. I trained and evaluated KNN models for multiple values of K (1 to 9), measuring their performance through accuracy, confusion matrices, and classification reports. To interpret how K impacts performance, I plotted a K vs Accuracy graph. For visual understanding, I also generated 2D decision boundary plots using the first two features. This task helped reinforce concepts like instance-based learning, distance metrics, and the importance of choosing the right K value in classification problems.
